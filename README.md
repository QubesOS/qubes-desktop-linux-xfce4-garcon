# Qubes garcon packaging (obsolete)

This repository is obsolete and no longer used. Qubes OS now has its own
[application menu](https://github.com/QubesOS/qubes-desktop-linux-menu).

It held the [Qubes OS](https://www.qubes-os.org) packaging of
[garcon](https://gitlab.xfce.org/xfce/garcon), the Xfce menu library: upstream
garcon plus a Qubes patch that reshaped Xfce's default application menu, adding
a "Qubes Tools" menu and a `qubes-manager` entry.
